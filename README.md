# Agenda de Tarefas

## Sobre o Projeto
Este projeto é uma aplicação web de **agenda de tarefas**, projetada para ajudar os usuários a organizar, acompanhar e gerenciar suas atividades diárias. A aplicação permite criar, visualizar, editar e excluir tarefas, oferecendo uma interface simples, intuitiva e funcional para melhorar a produtividade.

## Recursos
- **Adição de Tarefas:** Crie novas tarefas com título, descrição e prazo.
- **Edição de Tarefas:** Atualize detalhes de tarefas já criadas.
- **Exclusão de Tarefas:** Remova tarefas concluídas ou desnecessárias.
- **Listagem de Tarefas:** Veja todas as suas tarefas organizadas.
- **Interface Amigável:** Design simples e focado na experiência do usuário.
